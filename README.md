# AI-Recipe-Recommender

Project Description

AI Recipe Recommender is a web-based application that suggests recipes based on the ingredients avaible to the user. The project aims to help users decide what to cook by providing personalized meal suggestions.

Project Objectives

* Recommender recipes based on avaible ingredients.
* Help users reduce food waste.
* Provide simple and accessible cooking instructions.
* Explore the use of aertificial intelligence in everyday life.

Features

* Ingredient-based recipe recommendations.
* Recipe descriptions and preparation instructions.
* Estimated prepation and cooking times.
* A simple and user-friendly web interface.
* AI- powered recommendations (planned or implemented depending on the development stage).

Technologies

* Python
* Flask
* HTML
* CSS
* Artificial Intelligence
* Git and GitHub

Installation

1. Clone the repository:

git clone  https://github.com/Kayra-The-KayMira/AI-Recipe-Recommender.git

2. Navigate to the project directory:
cd AI-Recipe-Recommender

3. Install the required packages:
pip install -r requirements.txt

4. Start the application:
python app.py

5. Open the local address displayed in the terminaş in your web browser.

Usage

1. Open the web application.
2. Enter the ingredients avaible at home.
3. Submit the ingredients.
4. Review the recommended recipes and cooking instructions.
